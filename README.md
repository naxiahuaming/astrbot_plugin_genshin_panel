# 原神角色面板查询插件（AstrBot）

数据源与云崽Bot、早柚核心同源，均为 **Enka.Network** 公开接口，字段解析严格遵循
官方文档 <https://api.enka.network/#/api_chs>。无需用户 Cookie，无需登录。

## 一、安装

1. 把 `genshin_panel` 整个文件夹放入 AstrBot 根目录下的 `data/plugins/` 目录：
   ```
   AstrBot/
   └── data/
       └── plugins/
           └── genshin_panel/
               ├── __init__.py
               ├── main.py
               ├── metadata.yaml
               └── README.md
   ```
2. 打开 AstrBot Web 后台 → 插件市场 → 已安装，刷新后启用「原神角色面板查询」。
3. 若曾装过旧版本，请先删除旧插件目录再放入本版本，避免同名冲突。

## 二、使用

| 指令 | 说明 |
| --- | --- |
| `/查询角色 <UID> <角色名>` | 查询指定角色的完整面板，例：`/查询角色 100085620 奥黛塔` |
| `/查询角色 <UID>` | 列出该账号展柜中的全部公开角色 |
| `/查询角色 <UID> <序号>` | 按展柜顺序查询，例：`/查询角色 100085620 1` |
| `/查角色`、`/角色面板`、`/原神面板` | 同一指令的别名 |

角色名支持 **官方全名、部分名称、常用别名**（如 `水神` → 芙宁娜、`仆人` → 阿蕾奇诺、
`天鹅` → 奥黛塔）。

## 三、输出内容

- **基础信息**：等级、命之座、好感度、天赋等级（普攻 / 战技 / 爆发）
- **面板属性**：生命值上限、攻击力、防御力、暴击率、暴击伤害、元素充能效率、
  元素精通，以及非零的元素伤害加成
- **武器**：武器名、星级、等级、精炼阶数、基础攻击力与副属性
- **圣遗物**：部位、套装名、星级、强化等级、主词条与全部副词条

## 四、注意事项

1. 需在游戏内把**角色展柜设为公开**，并把要查询的角色放入展柜，接口才能取到数据
   （与云崽、早柚的要求完全一致）。私密展柜无法查询。
2. Enka 侧有约 1~2 分钟的缓存更新时间，刚更换展柜角色后请稍等再查。
3. 首次查询会从官方仓库下载静态数据表（角色 / 名称 / 圣遗物 / 武器），并缓存到
   **`data/plugin_data/genshin_panel/`** 目录（通过框架的 `StarTools.get_data_dir()`
   获取，符合插件持久化数据存放规范），之后启动无需重复下载。想强制更新数据，
   删掉该目录下的 `*.json` 文件即可。
4. 新角色只要能通过官方接口查到，名称会自动同步，不需要手动改代码。
5. 插件基于QQoffical官方机器人编写测试，未进行其他平台测试，返回结果为纯文本输出。

## 五、常见问题

- **提示未公开展柜**：确认游戏内展柜为公开状态，且展柜里有角色。
- **提示未匹配到角色**：指令只会列出**该账号展柜内**的角色；也可能是名称写法不同，
  可先只发 `/查询角色 <UID>` 查看展柜角色列表。
- **网络异常**：接口主站 `enka.network` 在部分网络下访问较慢，稍后重试即可。

## 六、数据目录

插件的静态数据缓存统一存放在：

```
AstrBot/
└── data/
    └── plugin_data/
        └── genshin_panel/
            ├── avatars.json   # 角色基础数据
            ├── locs.json      # 官方多语言名称表
            ├── relics.json    # 圣遗物套装数据
            └── weapons.json   # 武器数据
```

目录通过框架官方接口 `StarTools.get_data_dir("genshin_panel")` 获取，自动落在
`data/plugin_data/<插件名>`，不使用插件自身目录存放数据，便于数据迁移与审计。
